🔑 Implementation Pattern
────────────────────────────────────────────────────────────────────────────
User reads P1, P3, P7
  ↓ (fetch embeddings)
Compute user_profile = avg(embed(P1), embed(P3), embed(P7))
  ↓ (serialize to binary)
Query: WHERE vector MATCH serialize_float32(user_profile) ORDER BY distance
  ↓ (sqlite-vec KNN search)
Return top-k papers by lowest distance + filters

🔑 sqlite-vec API
────────────────────────────────────────────────────────────────────────────
Core: vec_distance_cosine(a.vector, b.vector)
Query: WHERE vector MATCH ? ORDER BY distance LIMIT k
Storage: BLOB format via serialize_float32()
Schema: CREATE VIRTUAL TABLE embeddings USING vec0(vector float[1024], +metadata)

🔑 Critical Implementation Details
────────────────────────────────────────────────────────────────────────────
1. Distance metric: Lower = more similar (ascending sort)
2. Vector serialization: serialize_float32() required for parameter binding
3. Metadata columns: Use + prefix (don't affect vectors)
4. Cold start: Return recent papers if no reading history
5. Performance: Excellent for <1M vectors (exact NN)
