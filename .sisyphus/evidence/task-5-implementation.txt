Core Functionality:
==================

1. BackgroundTaskManager class:
   - Constructor: new BackgroundTaskManager(maxConcurrent=4, maxTotal=8)
   - startBackgroundTask(pi, agent, task, onComplete?) → returns taskId
   - getTaskStatus(taskId) → "pending"|"running"|"completed"|"failed"|"cancelled"
   - getTaskResult(taskId) → AgentResult | null
   - cancelTask(taskId) → boolean
   - listActiveTasks() → TaskInfo[]
   - getStats() → stats object
   - cleanupOldTasks(maxAgeMs) → cleaned count

2. Concurrency Control:
   - Max 8 total tasks enforced
   - Max 4 concurrent tasks by default (configurable)
   - Slot-based semaphore pattern with executeWhenSlotAvailable()
   - AbortController-based cancellation

3. Task Lifecycle:
   pending → running → completed/failed/cancelled
   
   Task Info Structure:
   {
     id: string,
     agent: string,
     task: string,
     status: TaskStatus,
     startedAt: number,
     completedAt?: number,
     result?: AgentResult,
     error?: string
   }
