## 세계관 결정사항

### 확률 시스템
- 정부/시스템이 모든 시민을 실시간 감시·예측
- 스칼라는 확률 예측 불가 + **확률 조작 능력** 보유
- 확률 조작에는 리스크(탐지 상승)가 따름

### 스칼라가 예측 불가능한 이유
- 시스템 창조자 = 다른 세계의 스칼라
- 시스템이 "자기 자신"을 관측할 수 없는 구조적 맹점
- 플레이어가 게임 진행하면서 점진적으로 알아가는 미스터리 구조

### 스칼라를 쫓는 이유
- "예측 불가라서 위험" + "확률 조작 능력을 원해서" 둘 다

### 우주정거장
- 스칼라만의 은신처 (다른 주민 없음)
- 고독한 서바이벌 분위기

### 크리스탈
- AI + 휴머노이드 로봇
- 스칼라가 비밀리에 제작
- 확률 예측 가능 (적에게 들키면 행동이 읽힘)

### 엔딩
- 분기 없음. 하나의 확정된 결말.

## 게임플레이 결정사항

### 장르·구조
- 턴제 로그라이트 카드 게임
- 노드 베이스 맵 (슬레이 더 스파이어 방식)
- 하나의 긴 맵 (액트 구분 없음)
- 노드 약 18~22개
- 그리드 없음 (카드 전투만)

### 익스트랙션 루프
- 지구에 내려감 → 노드맵 탐색 → 물자·정보 획득 → 탈출 지점 도달
- 런 실패 시: 그 런 처음으로 리셋 (메타 진행은 유지)

### 노드 종류
- 전투 (경비 구역) 8~10
- 이벤트 (불확정 구역) 3~4
- 상점 (암거래상/해커) 2
- 은신처 (탐지 감소) 2
- 추적자 (엘리트) 2~3
- 물자 저장소 1~2
- 탈출 관문 1 (4웨이브 방어전)

### 전투 시스템
- 카드 시스템 (덱빌딩)
- 행동 포인트(AP) 소모로 카드 사용
- 적 행동 **전부 공개** (확률 포함: "공격 70% / 방어 30%")
- 적 하나씩 순서대로 행동
- 전투 승리 조건: 적 전멸

### 확률 조작 (코어 메카닉)
- 확률 조작 포인트(PP) 소모
- 턴마다 PP 회복
- AP와 PP는 별도 자원
- 조작 대상: 수치 (적중률, 회피율 등)
- 내 행동 성공률 ↑ / 적 행동 성공률 ↓ / 적 행동 자체를 다른 쪽으로 밀기 가능
- 드로우 확률도 조작 가능
- 노드맵에서도 사용 가능 (적 출현 확률 조작 등)
- **리스크: 탐지 단계 상승**

### 탐지 시스템
- 런 단위 리셋
- 전투 중에도 PP 사용 시 상승
- 단계별: 안전 → 주의 → 경계 → 추적
- 단계별로 적 추가, 추적자 출현, 이벤트 악화, 상점 이용 불가 등

### 카드 시스템
- 카드에 확률 내장 (강한 카드 = 낮은 기본 확률)
- 카드 레어리티 있음 (일반/희귀/전설)
- 총 카드 풀: 100~150장
- 런 시작 시 덱을 처음부터 구성
- 전투 보상 + 상점 + 이벤트에서 획득
- 스칼라 카드 / 크리스탈 전용 카드 / 공용 카드

### 키워드 시너지
- **과부하(Overload)**: 탐지 상승 대신 강력. 다수 사용 시 보너스
- **수렴(Converge)**: 같은 적 반복 시 강화. 보스킬러
- **분산(Scatter)**: 다수 적 확률 흔들기. 컨트롤형
- **은밀(Stealth)**: 탐지 안 오름. 은밀만 쓰면 탐지 감소
- **연산(Compute)**: 크리스탈 전용. 적 정보 정밀도 상승
- **링크(Link)**: 스칼라-크리스탈 연계 보너스

### 크리스탈 (전투 내)
- 별도 HP, 전투에 동행
- 크리스탈 전용 카드 (서포트: 정보, 실드, 탐지 감소)
- 크리스탈 경유 스칼라 카드 (크리스탈 생존 시에만 사용 가능)
- 적 행동 전부 공개하는 정보원 역할
- HP 0 시 현장 복구 가능 (물자 소모)

### 추적자(엘리트) 3종
- **탐지자(Detector)**: 매 턴 탐지 강제 상승. 빨리 처리해야 하는 타이머형
- **수렴자(Converger)**: PP 쓸수록 자기 공격이 100%로 수렴. 조작 억제
- **거울(Mirror)**: 스칼라의 확률 조작분만큼 자기 성공률도 상승. 조작 반동

### 탈출 관문
- 4웨이브 방어전
- 탈출선 도착까지 버티기

## 메타 진행 (런 사이)

### 정거장 업그레이드
- 시작 덱 커스터마이징
- 기본 AP/PP 증가
- 물자 소모

### 사전 준비 (런 출발 전)
- 가져갈 카드 덱 편집
- 크리스탈 장비/모듈 장착
- 물자 소모해서 소모품 제작
- (목적지 선택은 없음)

### 스토리 해금
- **경로 1**: 이벤트 노드에서 데이터 조각 획득 (물자 vs 데이터 트레이드오프)
- **경로 2**: 정거장에서 크리스탈과 대화 이벤트 (데이터 모으면 해금)
- 데이터 조각은 런 실패해도 유지
- 해금 흐름: 시스템 기원 → 관측불가 영역 단서 → 다른 세계 암시 → 창조자 확정 → 최종 진실
- 크리스탈도 "나는 왜 만들어졌는가" 의문을 품기 시작
